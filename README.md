A program that writes one funny line for make.fun's **"One Line, One Laugh"** bounty ($2 in USDC).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## What it does

`main.py` writes one line to `/output/entry.txt`:

> My plant died, so I bought a plastic one. Now I have to dust its corpse every week.

The plant died, the plastic replacement still demands chores — and "dust
its corpse" is the punchline.

The program is fully deterministic: the same 83-character line is written
on every run. It takes no input, makes no network calls, and needs no
dependencies beyond Python 3.

## The line

Fourteen candidate lines were drafted and scored pairwise against the
competition's judge brief — funniest first, then freshness, then whether
it lands instantly with no setup, then whether it is one self-contained
line. The plastic-plant line won: a real joke with a twist, a fresh angle
rather than a meme format, and it lands immediately.
